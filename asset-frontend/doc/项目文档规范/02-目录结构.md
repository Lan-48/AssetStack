## 文件命名规范

所有文件的命名，统一使用 **kebab-case（中划线命名法）**，即全小写字母，单词之间用中划线 `-` 分隔。

**基本规则**：
- ✅ 全部小写
- ✅ 单词之间用 `-` 连接
- ❌ 不使用驼峰命名（camelCase）
- ❌ 不使用下划线命名（snake_case）
- ❌ 不使用大写字母

**命名示例**：

| 文件类型 | 命名规范 | 示例 |
|---------|---------|------|
| 组件文件 | `[组件名].vue` | `uai-button.vue`、`user-info-card.vue` |
| 页面文件 | `[页面名]-page.vue` | `home-page.vue`、`user-detail-page.vue` |
| 页面子组件 | `[功能名]-part.vue` | `search-part.vue`、`product-list-part.vue` |
| Service | `[业务名]-service.ts` | `user-service.ts`、`auth-service.ts` |
| Function | `[功能名]-function.ts` | `permission-function.ts`、`validate-function.ts` |
| Store | `[状态名]-store.ts` | `user-store.ts`、`app-config-store.ts` |
| Utils | `[工具名].ts` | `date.ts`、`deep-clone.ts`、`format-price.ts` |
| Constants | `[常量类型]-constants-[平台].ts` | `business-constants-h5.ts`、`api-constants-weapp.ts` |
| Adapter | `[平台名]-[模块名]-adapter.ts` | `uni-cache-adapter.ts`、`weapp-storage-adapter.ts` |
| Factory | `[模块名]-factory.ts` | `http-client-factory.ts`、`logger-factory.ts` |
| Interface | `i-[接口名].ts` | `i-http-client.ts`、`i-logger.ts` |

**组件命名前缀规范**：
- **通用业务组件**：使用 `uai-` 前缀（UI Abstraction Interface）
  - 示例：`uai-button`、`uai-modal`、`uai-form`
  - 说明：便于识别和管理通用组件，避免命名冲突
- **页面特定组件**：无前缀，直接用功能名
  - 示例：`search-part`、`user-info-part`
